# awg-panel — панель управления с Windows

Интерактивное меню для сервера, развёрнутого этим репозиторием: список
клиентов, трафик, создание и удаление ключей, скачивание `.conf`, QR и
ссылки `vpn://`, резервные копии, перезапуск сервиса.

Повторяет набор команд `awg3.sh`, но с локальной машины и без запоминания
SSH-команд.

Панель устроена вглубь: **серверы → интерфейсы → ключи → карточка ключа**.
Каждый экран показывает краткий обзор уровня ниже, чтобы за ответом «а что там
внутри» не приходилось заходить внутрь. Возврат назад везде `0`, выход `Q`.

```
   СЕРВЕРЫ                          ИНТЕРФЕЙСЫ
    1  Домашний   admin@vpn1:2222    1  awg0  51820  10.9.0.1/24  3.1  2  active
       интерфейсов: 2, ключей: 3     2  awg1  51840  10.9.1.1/24  3.1  1  active
    2  Резервный  admin@vpn2:22      N  создать интерфейс
    N  добавить сервер               D  удалить интерфейс
    D  удалить сервер из списка      B  резервная копия сервера
    Q  выход                         M  разложить файлы по каталогам
                                     0  назад к серверам

   КЛЮЧИ ИНТЕРФЕЙСА awg0            КЛЮЧ my_phone
    1  my_phone  10.9.0.2  активен     адрес:     10.9.0.2/32
    2  laptop    10.9.0.3  3ч назад    версия:    3.1
    N  создать ключ                    совместим: да
    D  удалить ключ                    связь:     активен
                                       связь:     активен
   ИНТЕРФЕЙС awg0                      трафик:    принято 1.2 ГБ, отдано 340 МБ
    C  состояние (awg show)            откуда:    203.0.113.7:51820
    R  перезапустить сервис
    H  имя хоста для клиентов          1  скачать (conf + QR + ссылка)
    G  параметры обфускации            2  показать ссылку vpn://
    S  сменить общие параметры         3  переселить на другой интерфейс
    0  назад к интерфейсам             4  удалить ключ
                                       0  назад к ключам
```

Сводка в строке сервера («интерфейсов: 2, ключей: 3») появляется после того,
как вы на него зашли: опрашивать все сохранённые серверы разом нельзя — каждый
опрос это SSH-подключение, а на порт стоит `ufw limit`.

## Запуск

Скачайте обе папки в одно место и запустите `awg-panel.bat` двойным щелчком —
он сам найдёт PowerShell 7 или встроенный.

## Серверы

При запуске панель показывает список сохранённых серверов:

Выбор номера — вход **без единого вопроса**. Пароль не спрашивается, потому
что не используется: панель ходит по SSH-ключу.

**Добавление сервера** (`N`) — единственное место, где может понадобиться
пароль. Панель войдёт тем доступом, который у вас уже есть: ключом из агента,
ключом по умолчанию, а если их нет — по паролю, который спросит сам `ssh`.
Панель пароль не видит и не хранит. Дальше она сама:

1. создаст ключ `~/.awg-panel/id_ed25519`, если его ещё нет;
2. положит публичную половину в `~/.ssh/authorized_keys` на сервере;
3. пропишет `sudo` право запускать **только** `awg3.sh` без пароля;
4. проверит, что вход по ключу работает, и лишь тогда сохранит профиль.

Пароль на этом шаге спрашивается до двух раз: вход на сервер (если ключ не
подошёл) и `sudo` уже на самом сервере. Так работает `ssh`: пароль он читает
прямо с клавиатуры, и передать его за вас панель не может — и не должна.

Если войти не удалось совсем — например, на сервере выключен вход по паролю, а
ключа панели там ещё нет, — она покажет свой публичный ключ и две готовые
команды: добавить его в `authorized_keys` и выдать право на `awg3` без пароля.
Выполните их любым работающим доступом и ответьте «да» на предложение
проверить ещё раз.

Возиться с ключами вручную не нужно — всё делается за вас.

**Удаление** (`D`) убирает сервер только из списка на вашей машине. Ключ на
сервере остаётся в `~/.ssh/authorized_keys` — уберите его там, если доступ
больше не нужен.

Умолчания при добавлении: порт `22`, пользователь `user`. Если хотите другие,
поправьте начало `awg-panel.ps1`:

```powershell
$DefaultHost = 'vpn.example.com'
$DefaultPort = 2222
$DefaultUser = 'vpnadmin'
```

## Интерфейсы

Второй уровень. Интерфейсов на сервере может быть несколько, и они независимы:
свой порт, подсеть, общие параметры и каталог ключей. Выбрали номер — оказались
внутри, среди его ключей; где вы находитесь, видно в шапке:
`admin@vpn1:2222 › awg1 › my_phone`.

Здесь же интерфейс можно **создать** (`N`) и **удалить** (`D`). При создании
спрашиваются порт и подсеть, имя `awg3` выбирает сам — первое свободное; порт в
фаерволе открывается тоже сам. Удаление уносит с собой ключи интерфейса,
поэтому подтверждение строгое: имя целиком.

Если интерфейс создан до 3.1, панель предупредит об этом при входе: новых
ключей на нём выдать нельзя, пока не прошёл `S` — смена общих параметров.
Причина не в панели: `RandomTrailers` обязан совпадать на обоих концах, и ключ,
выданный на таком интерфейсе, молча не подключился бы.

Сменить порт или подсеть существующего интерфейса нельзя — это пересоздание,
то есть `D` и следом `N`. Отдельного пункта для этого нет намеренно: он делал
бы вид, что правит одно поле, а на деле пересобирал бы интерфейс целиком.

## Ключи

Третий уровень — список ключей интерфейса с адресом, версией, связью и
колонкой «совместим». Красная строка означает, что ключ выдан до смены общих
параметров и не подключится: по самому конфигу этого не видно.

Создать ключ — `N`, удалить — `D` с выбором из списка. Оба действия здесь же,
как у интерфейсов уровнем выше.

Четвёртый уровень — карточка ключа: адрес, трафик, откуда последний раз
подключался, и четыре действия — скачать (conf + QR + ссылка `vpn://`),
показать ссылку, переселить на другой интерфейс, удалить. Удаление из карточки
и из списка — одно и то же: подтверждение и чистка локальной папки общие.

**Переселение** заводит ключ на другом интерфейсе с той же парой ключей: на
сервере это остаётся тот же пир, у человека — та же личность. На исходном
интерфейсе ключ остаётся, поэтому прежняя ссылка продолжает работать, пока
человек не импортирует новую. Когда переедет — удалите его на прежнем
интерфейсе.

## Что нужно на вашей машине

Ничего устанавливать не нужно — панель обходится тем, что уже есть в Windows:

- PowerShell 5.1 или новее (PowerShell 7 предпочтительнее) — встроен;
- «Клиент OpenSSH» (`ssh.exe` и `ssh-keygen.exe`) — в Windows 10 и 11 стоит из
  коробки.

Если `ssh` всё же не найден: Параметры → Приложения → Дополнительные
компоненты → Добавить компонент → «Клиент OpenSSH».

## Что нужно на сервере

Развёрнутый этим репозиторием AmneziaWG: панель вызывает `~/awg/awg3.sh`
через `sudo` от указанного пользователя. При добавлении сервера вход идёт по
паролю, поэтому `PasswordAuthentication` должен быть включён (по умолчанию так
и есть — `bootstrap.sh` его не отключает). Дальше он уже не нужен.

## Про безопасность

Пароль нужен **только при добавлении сервера**, и спрашивает его сам `ssh` —
панель его не получает, не хранит и не пересылает. Ни в памяти PowerShell, ни
в аргументах команды (они видны в списке процессов любому пользователю
системы) он не появляется вовсе. Дальше вход идёт по ключу, и пароль не
запрашивается больше никогда.

Право `sudo` без пароля выдаётся узко — только на `awg3.sh`, а не на всю
систему. Если ключ утечёт, потеря ограничена управлением VPN, и отзывается
он удалением одной строки из `~/.ssh/authorized_keys` — менять пароль
учётной записи не придётся.

Отпечаток сервера запоминается при первом подключении в
`~/.awg-panel/known_hosts` — отдельно от вашего личного `~/.ssh/known_hosts` —
и сверяется дальше. Первый раз его показывает и спрашивает сам `ssh`; ответ
`yes` целиком. Если отпечаток изменился, панель покажет предупреждение и
предложит забыть прежний — пароль при этом никуда не отправляется.
Подтверждение снова строгое, `yes` целиком: согласие здесь означает готовность
разговаривать с тем, кто отвечает по этому адресу. Соглашайтесь, только если
сервер переустанавливали вы сами.

Каждое действие — отдельное SSH-подключение. Панель не держит открытую
сессию, поэтому забытое окно не оставляет висящего доступа к серверу.

Учтите, что на сервере работает fail2ban: несколько неверных паролей подряд
заблокируют ваш адрес примерно на 10 минут.

## Создание ключа

При создании панель спрашивает имя, профиль мимикрии, интенсивность и **имя
хоста для клиентского `Endpoint`**. По умолчанию предлагается тот адрес, по
которому подключились вы сами, — раз он работает отсюда, скорее всего
заработает и у клиента. Если у сервера есть отдельное DNS-имя, укажите его:
тогда при смене IP выданные конфиги останутся рабочими.

Готовые файлы скачиваются в папку рядом с панелью: `ИМЯ/ИМЯ.conf`,
`ИМЯ/ИМЯ.png` и `ИМЯ/ИМЯ.vpnuri` — ссылка `vpn://` для приложения
AmneziaVPN. Панель предложит сразу положить её в буфер обмена.

У клиентов, созданных прежними версиями `awg3.sh`, файла со ссылкой на
сервере нет: панель попросит собрать его командой `awg3 link ИМЯ` по
готовому конфигу. На сервере со старым скриптом такой команды не найдётся —
тогда скачаются только конфиг и QR.
