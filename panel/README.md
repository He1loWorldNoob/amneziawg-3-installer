# awg-panel — панель управления с Windows

Интерактивное меню для сервера, развёрнутого этим репозиторием: список
клиентов, трафик, создание и удаление ключей, скачивание `.conf` и QR,
резервные копии, перезапуск сервиса.

Повторяет набор команд `awg3.sh`, но с локальной машины и без запоминания
SSH-команд.

```
   ╔══════════════════════════════════════════════╗
   ║        AmneziaWG — панель управления         ║
   ╚══════════════════════════════════════════════╝

   КЛЮЧИ
    1  Список клиентов
    2  Трафик и активность
    3  Создать ключ
    4  Скачать ключ (conf + QR)
    5  Удалить ключ

   СЕРВЕР
    6  Состояние (awg show)
    7  Перезапустить сервис
    8  Резервная копия
    9  Имя хоста для клиентов

   ПРОЧЕЕ
    G  Показать набор параметров обфускации
    M  Разложить файлы по каталогам
    S  Сменить общие параметры сервера
```

## Запуск

Скачайте обе папки в одно место и запустите `awg-panel.bat` двойным щелчком —
он сам найдёт PowerShell 7 или встроенный.

## Серверы

При запуске панель показывает список сохранённых серверов:

```
  Куда подключаемся

   1  Домашний    admin@vpn.example.com:2222
   2  Резервный   admin@203.0.113.10:22

    N  добавить новый
    D  удалить из списка
    Q  выход
```

Выбор номера — вход **без единого вопроса**. Пароль не спрашивается, потому
что не используется: панель ходит по SSH-ключу.

**Добавление сервера** (`N`) — единственное место, где нужен пароль. Панель
спросит адрес, порт, пользователя и пароль, после чего сама:

1. создаст ключ `~/.awg-panel/id_ed25519`, если его ещё нет;
2. положит публичную половину в `~/.ssh/authorized_keys` на сервере;
3. пропишет `sudo` право запускать **только** `awg3.sh` без пароля;
4. проверит, что вход по ключу работает, и лишь тогда сохранит профиль.

Возиться с ключами вручную не нужно — всё делается за вас. Пароль после
этого нигде не остаётся: ни на диске, ни в памяти панели.

**Удаление** (`D`) убирает сервер только из списка на вашей машине. Ключ на
сервере остаётся в `~/.ssh/authorized_keys` — уберите его там, если доступ
больше не нужен.

Умолчания при добавлении: порт `22`, пользователь `user`. Если хотите другие,
поправьте начало `awg-panel.ps1`:

```powershell
$DefaultHost = 'vpn.example.com'
$DefaultPort = 2222
$DefaultUser = 'vpnadmin'
```

## Что нужно на вашей машине

- Windows с PowerShell 5.1 или новее (PowerShell 7 предпочтительнее)
- Python — при установке отметьте «Add python.exe to PATH»

Библиотеку `paramiko` панель ставит себе сама при первом запуске, в отдельное
окружение `.venv` рядом с `awg-panel.ps1`. Системный Python она не трогает:
права администратора не нужны, и с пакетами системы такая установка не спорит.
Если окружение испортилось, удалите папку `.venv` — панель создаст его заново.

## Что нужно на сервере

Развёрнутый этим репозиторием AmneziaWG: панель вызывает `~/awg/awg3.sh`
через `sudo` от указанного пользователя. Вход по паролю, поэтому
`PasswordAuthentication` должен быть включён (по умолчанию так и есть —
`bootstrap.sh` его не отключает).

## Про безопасность

Пароль нужен **только при добавлении сервера**, нигде не сохраняется и
передаётся помощнику через stdin, а не аргументом командной строки: аргументы
видны в списке процессов любому пользователю системы. Дальше вход идёт по
ключу, и пароль не запрашивается вовсе.

Право `sudo` без пароля выдаётся узко — только на `awg3.sh`, а не на всю
систему. Если ключ утечёт, потеря ограничена управлением VPN, и отзывается
он удалением одной строки из `~/.ssh/authorized_keys` — менять пароль
учётной записи не придётся.

Отпечаток сервера запоминается при первом подключении в
`~/.awg-panel/known_hosts` и сверяется дальше. Если он изменился, панель
покажет оба значения и предложит забыть прежний — пароль при этом не
отправляется. Подтверждение строгое: нужно ввести `yes` целиком, потому что
согласие здесь означает готовность отдать пароль тому, кто отвечает по этому
адресу. Соглашайтесь, только если сервер переустанавливали вы сами.

Каждое действие — отдельное SSH-подключение. Панель не держит открытую
сессию, поэтому забытое окно не оставляет висящего доступа к серверу.

Учтите, что на сервере работает fail2ban: несколько неверных паролей подряд
заблокируют ваш адрес примерно на 10 минут.

## Создание ключа

При создании панель спрашивает имя, профиль мимикрии, интенсивность и **имя
хоста для клиентского `Endpoint`**. По умолчанию предлагается тот адрес, по
которому подключились вы сами, — раз он работает отсюда, скорее всего
заработает и у клиента. Если у сервера есть отдельное DNS-имя, укажите его:
тогда при смене IP выданные конфиги останутся рабочими.

Готовые файлы скачиваются в папку рядом с панелью: `ИМЯ/ИМЯ.conf` и
`ИМЯ/ИМЯ.png`.
